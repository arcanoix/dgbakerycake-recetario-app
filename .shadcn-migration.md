# Guía de Migración a shadcn/ui

## Reemplazos Globales de Colores

### Fondos
- `bg-white` → `bg-background` o `bg-card`
- `bg-gray-50` → `bg-muted`
- `bg-gray-100` → `bg-muted`
- `bg-slate-50` → `bg-muted/50`

### Textos
- `text-gray-900` → `text-foreground`
- `text-gray-700` → `text-muted-foreground`
- `text-gray-600` → `text-muted-foreground`
- `text-slate-700` → `text-muted-foreground`

### Bordes
- `border-gray-200` → `border`
- `border-gray-300` → `border`
- `border-slate-200` → `border`

### Hover States
- `hover:bg-gray-100` → `hover:bg-accent`
- `hover:text-gray-900` → `hover:text-accent-foreground`

### Estados Activos
- `bg-violet-50` (active) → `bg-accent`
- `text-violet-700` (active) → `text-accent-foreground`

### Destructive (Eliminar/Peligro)
- `text-red-600` → `text-destructive`
- `hover:bg-red-50` → `hover:bg-destructive/10`
- `border-red-200` → `border-destructive`

## Componentes a Usar

### Badges
Reemplazar spans con clases de color por:
```tsx
<Badge variant="secondary">Categoría</Badge>
<Badge variant="destructive">Error</Badge>
<Badge variant="outline">Info</Badge>
```

### Buttons
Ya están bien, pero asegurar variantes:
```tsx
<Button variant="outline">Acción</Button>
<Button variant="destructive">Eliminar</Button>
<Button variant="ghost">Cancelar</Button>
```

### Cards
```tsx
<Card className="hover:shadow-md transition-shadow">
  <CardHeader>
    <CardTitle>Título</CardTitle>
    <CardDescription>Descripción</CardDescription>
  </CardHeader>
  <CardContent>
    Contenido
  </CardContent>
</Card>
```

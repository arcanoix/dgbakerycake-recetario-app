## 🔧 **Componentes Reemplazados**

### **Badges**
**Antes:**
```tsx
<span className="bg-blue-100 text-blue-800 text-xs px-2.5 py-1 rounded-full">
  Categoría
</span>
```

**Ahora:**
```tsx
<Badge variant="secondary">Categoría</Badge>
```

### **Botones Destructivos**
**Antes:**
```tsx
<Button className="hover:bg-red-50 border-red-200 text-red-600">
  Eliminar
</Button>
```

**Ahora:**
```tsx
<Button variant="outline" className="text-destructive hover:bg-destructive/10">
  Eliminar
</Button>
```

### **Cards**
**Antes:**
```tsx
<div className="bg-white border border-gray-200 rounded-lg shadow-sm">
  <div className="p-4">
    <h3 className="text-lg font-bold text-gray-900">Título</h3>
    <p className="text-sm text-gray-600">Descripción</p>
  </div>
</div>
```

**Ahora:**
```tsx
<Card className="hover:shadow-md transition-shadow">
  <CardHeader>
    <CardTitle>Título</CardTitle>
    <CardDescription>Descripción</CardDescription>
  </CardHeader>
  <CardContent>
    Contenido
  </CardContent>
</Card>
```

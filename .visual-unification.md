## 📊 **ESTRUCTURA VISUAL UNIFICADA**

Todos los componentes de lista ahora siguen este patrón:

```tsx
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
  {items.map((item, index) => (

      <Card className="group hover:shadow-lg transition-all duration-300 hover:-translate-y-1 overflow-hidden">
        <CardHeader className="pb-3">

              </CardTitle>
            </div>
            <Badge variant="secondary" className="flex-shrink-0">
              Categoría
            </Badge>
          </div>
          <CardDescription className="line-clamp-2 mt-2">
            Descripción del item
          </CardDescription>
        </CardHeader>
        
        <CardContent className="space-y-4">
          <div className="bg-muted/50 rounded-lg p-4 space-y-3 border">
            {/* Información principal */}
          </div>
          
          <div className="flex gap-2">
            <Button variant="outline" size="sm" className="flex-1 gap-1.5">
              <Edit2 className="w-3.5 h-3.5" />

          </div>
        </CardContent>
      </Card>
    </motion.div>
  ))}
</div>
```

## 🎨 **ELEMENTOS VISUALES CONSISTENTES**

### **Grid Layout**
```tsx
className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6"
```
- **Mobile:** 1 columna
- **Tablet:** 2 columnas
- **Desktop:** 3 columnas
- **Gap:** 1.5rem (24px)

### **Card Hover Effects**
```tsx
className="group hover:shadow-lg transition-all duration-300 hover:-translate-y-1"
```
- Sombra más pronunciada al hover
- Elevación sutil (-4px en Y)
- Transición suave de 300ms

### **Animaciones de Entrada**
```tsx
initial={{ opacity: 0, y: 20 }}
animate={{ opacity: 1, y: 0 }}
transition={{ delay: index * 0.05, duration: 0.3 }}
```
- Fade in desde abajo
- Delay escalonado (50ms por item)
- Duración de 300ms

### **Header Structure**
- **Título:** `CardTitle` con icono a la izquierda
- **Badge:** A la derecha del título
- **Descripción:** `CardDescription` opcional debajo

### **Content Section**
- **Fondo:** `bg-muted/50` con border
- **Padding:** `p-4`
- **Espaciado:** `space-y-3`

### **Action Buttons**
- **Layout:** `flex gap-2`
- **Editar:** `flex-1` (ocupa espacio disponible)
- **Otros:** Tamaño fijo
- **Eliminar:** `text-destructive hover:bg-destructive/10`
